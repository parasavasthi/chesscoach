# ChessCoach Architecture

## Goal
Build a GPT-powered chess coach that can fetch games, analyse them, identify patterns, and provide training recommendations.

## Components
- Custom GPT
- Chess.com Public API
- Backend API
- Stockfish Engine
- Analysis Database (future)

## Roadmap
1. Chess.com integration
2. GPT Actions
3. Backend service
4. Stockfish analysis
5. Coaching and progress tracking
